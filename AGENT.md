# Wireproxy Desktop — agent notes

- Keep work local unless the user explicitly asks to push or publish. Preserve the existing working tree and inspect `git status --short` before editing.
- `README.md` is Russian. Keep `README.en.md` synchronized and use a screenshot in the matching language. Keep both READMEs general and verify stable download URLs against GitHub Releases.
- Use synthetic profiles and documentation-range endpoints for screenshots. Start a copy of the local executable with `--portable` in a disposable directory. Remove only that test directory and its own protected-store entry afterwards. Avoid showing keys, passwords, logs, or real endpoints in screenshots.
- The root `main.go` dispatches executable modes. `internal/desktop` owns the Gio window, tray and GNOME integration, `internal/tunnel` owns the session and SOCKS5 worker, and `internal/profile` owns profile parsing and conversion. Keep blocking network and keyring work off the GUI loop. SOCKS5 test and URL copy require a confirmed, current handshake. Keep the protocol shown for the profile distinct from the engine version.
- `internal/config` handles migration and scope. The platform backends use DPAPI plus the user registry, macOS Keychain, and Linux Secret Service. Preserve old JSON until a protected copy has been read back and verified. Avoid plaintext fallback. Never log profile contents or credentials.
- The release workflow is `.github/workflows/build.yml`. Add the matching `## vX.Y.Z` section to `CHANGELOG.md` before tagging. GitHub Actions injects the tag into `main.version` and publishes six platform builds (including two Linux install archives) plus `SHA256SUMS`. Keep asset names in sync with `PlatformAsset` in `internal/updater`.
- Use the Go version in `go.mod`. The devcontainer provides the Linux graphics build dependencies. Run `go test -tags novulkan ./...` there. Use `sh scripts/build-linux.sh` for the Linux release layout in `dist/`. Windows uses `CGO_ENABLED=0`. macOS uses CGO and Xcode tools. Its release builds use ad hoc signing. Verify Gatekeeper on an actual Mac when validating the download experience.
- Edit app and tray assets together. After changing `assets/favicon.ico`, run `go generate -run go-winres .` to refresh both Windows resource objects. Validate the compiled executable icon separately from Explorer's cached display.
